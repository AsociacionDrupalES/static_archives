Drupal como framework de aplicaciones web

  • aplicaciones web
  • framework
Tweet

En ocasiones se habla de Drupal como un CMS (content management system); no obstante, este punto de vista se queda bastante corto porque Drupal va mucho más allá.

Drupal es un framework para el desarrollo de aplicaciones web. Como framework ofrece un conjunto de facilidades o servicios, como la gestión de usuarios, la infraestructura para la gestión de nodos, taxonomía, acceso a base de datos, gestión de ficheros, caché y un largo etcétera.

En esta sesión profundizaría en estos conceptos y mostraría a un público tanto newbie como experimentado las ventajas (y necesidad) de iniciar un proyecto web usando un framework como Drupal.
