Caching out on Nginx

  • cloud
  • high performance
  • nginx
  • rendimiento
  • security
Tweet

Nginx is a high-performance, modern, secure web server that is taking the web by storm.

In this session we address the practical issues of using Nginx with drupal and how to take advantage to the fullest of running Drupal behind Nginx.

We take into consideration also the security benefits and the several strategies that can be employed for mitigating several types of attacks.

This session articulates with the planned drupal performance showdown . We will discuss how we built our Nginx setup and explain the rationale behind the choices that we made.
