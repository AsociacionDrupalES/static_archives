Drupal facebook integration

  • drupal facebook
  • drupal facebook integration
Tweet

English:
This session would be a detailed look into the functionality that facebook offers and how to implement all that power in drupal.
We would start with facebook popular concepts like "Social Plugins,
Social Channels, Graph API and authentification".
Thereafter we would go through most of the important contributed modules that you can use for implementing the above mentioned concepts.
Lastly we would show you how to do some really cool stuffs from your own module like registering users and importing facebook profile to your profile content type in drupal.
Questions and answer session would be in both spanish and english

Spanish:
Esta sesión será una mirada detallada de la funcionalidad disponible que
ofrece facebook y la forma de llevar todo este poder a una aplicación de
Drupal.
Empezaremos con conceptos de facebook como "Social Plugins,
Social Channels, Graph API and authentification". Seguidamente iremos
directamente a Drupal y a estudiar cómo hacer algunas cosas interesantes con
los módulos de Drupal disponibles.
Por último miraremos cómo hacer mas cosas de facebook desde su propio módulo como registrar usuarios y importar perfiles de facebook.
La parte de preguntas será en castellano i ingles
