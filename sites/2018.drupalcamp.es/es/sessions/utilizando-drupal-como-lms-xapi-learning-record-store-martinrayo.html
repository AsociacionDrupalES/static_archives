Utilizando Drupal como LMS + xAPI + Learning Record Store

Raúl Bordallo

Tipo de charlas: Standard (45 min)
Nivel de charlas: Basic
Session language: Spanish
Drupal es una gran herramienta para desarrollar un Learning Management System (LMS), en esta charla pretendo explicar qué aporta Drupal a la nueva manera de entender, medir y adaptar el eLearning. Así como la definición y flujo de información.

Mediante la integración con el standard Experience API (xAPI) y la recolección y el almacenaje de información en los Learning Record Store (LRS) se puede medir y ser utilizados para mejorar el eLearning (Learning Analytics).

Veremos un ejemplo completo utilizando Drupal como LMS, definición de statements en xAPI para recolectar información de nuestro Drupal, envío y almacenaje en el LRS y visualización de datos.

LMS: Learning Management System
xAPI: Experience API, antes Tin Can API
LRS: Learning Record Store

Bonus: ¿Y si los datos del LRS están almacenados en la BlockChain?

Slides de la charla: https://es.slideshare.net/rbordallo/xapi-lrs-drupal-midiendo-para-mejorar
