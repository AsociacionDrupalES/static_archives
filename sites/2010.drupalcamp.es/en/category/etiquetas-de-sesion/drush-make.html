Feature Server es un sistema Drupal que permite mantener un catálogo de proyectos (Módulos, Temas y Perfiles de instalación) y de sus versiones, y permite a otros sitios Drupal conocer las últimas actualizaciones, mediante el módulo Update status del core

Drush Make permite describir cuales son los proyectos que forman un sitio Web en un archivo Make y ejecutarlo para construir automáticamente el codebase de un sitio.
