Feature Server es un sistema Drupal que permite mantener un catálogo de proyectos (Módulos, Temas y Perfiles de instalación) y de sus versiones, y permite a otros sitios Drupal conocer las últimas actualizaciones, mediante el módulo Update status del core

Drush Make permite describir cuales son los proyectos que forman un sitio Web en un archivo Make y ejecutarlo para construir automáticamente el codebase de un sitio.

Conjuntamente, ambas innovaciones, permiten desarrollar sitios Web manteniendo diferentes instancias de servidores desarrollo, staging y producción. Agilizando el proceso de desarrollo y mejorando, enormemente la mantenibilidad del sistema.

En esta sesión pondremos en marcha y empezaremos a utilizar un Feature Server, subiremos algunos proyectos y demostraremos como es posible montar nuevas instancias de un sitio Web con Drush Make y mantener las existentes actualizadas.
