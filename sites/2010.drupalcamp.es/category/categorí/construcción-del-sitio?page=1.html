10 Pasos básicos para crear un sitio web (un blog personal o un sitio de noticias de una asociación), con Drupal.

1.- Nombre del sitio... ¿Dominio?.
2.- Alojamiento: ¿Hotel o Apartamento?... No!!!, hosting.
3.- ¿Y la Base de Datos?. - Fácil, desde el Panel de Control.
4.- Conseguir el paquete DRUPAL en... DRUPAL.ORG, ¿donde sino?
5.- Subir el paquete mediante FTP... (¿ya tienes un FTP?... no te preocupes, te diremos donde obtenerlo)
6.- Instalar DRUPAL !!!
7.- Seguir la chuleta para configurar las opciones iniciales.
