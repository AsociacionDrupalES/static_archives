Building Maps with OpenLayers in Drupal

In English. I will demo and describe how you can make beautiful maps with the Drupal OpenLayers module, specifically with the (still being developed) 2.x branch that has some great new features.

OpenLayers is a free, open-source Javascript library that allows for the presentation of mapping data within a website. The Drupal OpenLayers modules provides an API to build, store, and present maps easily from the Drupal interface.
