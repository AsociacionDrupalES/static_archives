Puedo usar el PC de la sala (con Linux)

Como buena navaja suiza que es, Drupal nos ofrece toda la funcionalidad para la creación de una red social que permita a los usuarios disfrutar de un sitio web donde además de leer y comentar, puedan participar activamente.

Se presentarán las ventajas y dificultades que nos podemos encontrar, así como la introducción a algunos módulos que permiten añadir las características habituales de un sitio social. Algunas funcionalidades que se presentarían:

Perfiles de usuario con Content Profile
Grupos con Organic Groups
Relaciones entre usuarios con User Relationships
Mensajería privada con Privatemsg
Mensajes de estado con Facebook Style Status
Registro de actividad del sitio con Activity

Documentación
